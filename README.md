# 灌区配水核算台

灌区调度员在送水前核对闸令、渠道损耗与斗口的当轮配额，再生成回执草案。工作台可切换干净和脏样例，核算后下载一份带原始行与规则版本的证据。

```sh
docker compose up --build
```

访问 `http://127.0.0.1:18449`，先看尾量调平，再点取水权版本和渠道损耗复核来源。脏样例有交叠权证和分支闸门冲突，回执保持待审。`docker compose exec -T app pytest -q` 运行测试。默认命名卷 `records` 保存归档，宿主变量 `DB_PATH` 可指定 SQLite 文件。宿主运行可先安装 `requirements.txt`，再执行 `uvicorn app.main:app --port 18449`。

## 放水中途故障改派（M8）

支渠闸门在放水中途故障时，`POST /api/incidents` 提交故障号、故障渠段和各斗口已放量，工作台在**不改动已发生放水量**的前提下，把故障子树斗口立即停闸、影响不明斗口挂起，并将全部未放水量按“保底优先、原轮灌顺序灌满、余水留渠尾”重排成唯一可执行的先停后开指令。台账逐项对平原安排、已放量、新安排与待处理水量（守恒式：原安排 = 已放量 + 新安排 + 渠尾余水）。同一故障号重试幂等返回首次改派账，不重复扣减，换底账则拒绝覆盖。样例见 `sample_data/fault_incident.json`，页面在 `/work/incidents`。
